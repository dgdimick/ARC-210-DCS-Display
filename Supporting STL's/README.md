# ARC-210 Supporting 3D Files

## Knob Set V3

Updated October 4, 2026.

**Knob Set V3** identifies this collection. Each knob retains its own revision number; the collection number does not reset or replace those numbers.

### Current published knobs

| Knob | Current STL | Earlier file |
| --- | --- | --- |
| Frequency | [Freq_Knob_v10.stl](Freq_Knob_v10.stl) | Replaces `Freq Mesh v9.stl` |
| Mode | [Mode_Knob_v4.stl](Mode_Knob_v4.stl) | Supersedes `Mode Mesh v6.stl`, despite its higher filename number |

### If you downloaded an older ZIP

Download the current files linked above. Do not mix the older frequency or mode STLs with Knob Set V3. The old filenames have been removed from the current branch, but may still exist in previously downloaded ZIPs or repository history.

`Channel Knob v13.stl` was also removed during this update. It is not included in the current published collection; the separately revised channel knob has not yet been uploaded. The mode knob is not a substitute for the channel knob.

### Printing and fit

Use the hardware listed on the main project page. Earlier printing notes reported needing 106% scale for the mode and frequency knobs on the author's printer. That is a historical fit adjustment, not a verified requirement for every current STL or printer. Check shaft fit before printing the full set; scaling changes both the outside dimensions and the holes.

## Display bracket

The 3.5 SPI display mount does not have mounting points. It is a bracket that holds the display between the PCB and front face and currently needs to be hot-glued in place. A proper mounting arrangement is planned.
