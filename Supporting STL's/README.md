## Knob Set V3

Updated October 4, 2026.

**Knob Set V3** identifies this collection. Each knob retains its own revision number; the collection number does not reset or replace those numbers.

### If you downloaded an older ZIP

Download the current files linked above. Do not mix the older frequency, mode, or channel STLs with Knob Set V3. The old filenames have been removed from the current branch, but may still exist in previously downloaded ZIPs or repository history.

`Channel_Knob_v3.stl` is the current channel knob for Knob Set V3. Its lower filename number does not mean it is older than `Channel Knob v13.stl`. Use the linked files above to identify the current versions.

### Printing and fit

Use the hardware listed on the main project page. Earlier printing notes reported needing 106% scale for the mode and frequency knobs on the author's printer. That is a historical fit adjustment, not a verified requirement for every current STL or printer. Check shaft fit before printing the full set; scaling changes both the outside dimensions and the holes.

## Rotary encoder spacer

Added October 11, 2026.

[Rotary Encoder Spacer.stl](Rotary%20Encoder%20Spacer.stl)

I use this spacer around the rotary encoder's threaded mounting section because the PC Flights ARC-210 faceplate has 10 mm holes, which are larger than the encoder threads. The spacer fills the gap and centers each encoder in its faceplate hole. Print six spacers for the six rotary encoders, and check the fit before printing the full set.

PC Flights has supplied me with a drawing file to assist with the Button PCB layout.

## On/Off rotary switch support spacer

[Shaft Spacer.stl](Shaft%20Spacer.stl)

The **On/Off rotary switch PCB** will be attached to the main board, so use this spacer to support the switch shaft.
