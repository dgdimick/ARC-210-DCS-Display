Pin Layout

ARC-210 Teensy 4.1


| Function       | Actual Teensy GPIO | KiCad U1 terminal(s) |
| -------------- | -----------------: | -------------------: |
| Panel LED PWM  |                  5 |                    7 |
| TFT BLK PWM    |                  4 |                    6 |
| TFT RESET      |                  8 |                   10 |
| TFT MOSI       |                 11 |                   13 |
| TFT DC/RS      |                  9 |                   11 |
| TFT CS         |                 10 |                   12 |
| TFT SCK        |                 13 |                   35 |
| Encoder 1      |             16, 17 |               38, 39 |
| Encoder 2      |             28, 29 |               20, 21 |
| Encoder 3      |             20, 21 |               42, 43 |
| Encoder 4      |             22, 23 |               44, 45 |
| Encoder 5      |             24, 25 |               16, 17 |
| Encoder 6      |             26, 27 |               18, 19 |
| Matrix rows    |     30, 31, 32, 33 |       22, 23, 24, 25 |
| Matrix columns |     35, 36, 37, 40 |       27, 28, 29, 32 |
| SPST           |                 41 |                   33 |
| I²C reserved   |             18, 19 |               40, 41 |

GPIO numbers are the labels printed on the Teensy and the numbers used in Arduino code.
The terminal column uses the KiCad Teensy4.1 symbol U1 numbering, not display connector numbering.
For rows with multiple pins, both columns correspond in the same left-to-right order.

TFT BLK PWM wiring (confirmed working):
- Teensy board printed pin label: 4
- GPIO / Arduino code pin number: 4
- KiCad Teensy symbol U1 terminal number: 6
These identify the same connection. BLK uses GPIO 4, not GPIO 6.
Reserve this connection for the display backlight PWM.
PWM dimming has been verified in the standalone test. Integration into
Master_Program is deferred until the final test.
