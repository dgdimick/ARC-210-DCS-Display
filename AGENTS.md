# Main README date

## All documentation page timestamps

Every user-facing Markdown page must have a visible `**Last updated: October 30, 2026 at 9:15 PM MDT (America/Denver)**` line directly below its main heading. This is a format example: always use the actual current America/Denver date and time, with the correct MST/MDT abbreviation.

Whenever a page changes, refresh its timestamp in the same commit. Whenever repository files change, also refresh the root README's page timestamp and header date. When changing downloadable files or hardware/firmware assets, refresh the timestamp on their documentation/download page too. Preserve historical release dates, dated project entries, and test dates. Documentation-only edits must not create hardware/firmware progress entries. AGENTS.md instruction files and third-party license texts are not user-facing documentation pages and do not need timestamps.

Whenever repository changes are made, refresh the date in the root README's main header in the same commit so it shows the date of the latest project changes. Use the actual current date in America/Denver, formatted as `October 30, 2026`. Preserve historical release and test dates and follow any more specific instructions in subdirectories.
